This is a genuinely difficult book that builds functional concepts — algebraic data types, effects, persistent data structures — from scratch rather than just showing Kotlin's map/filter/fold. Not a book for learning Kotlin; it's a book for learning functional programming that happens to use Kotlin as its vehicle.
