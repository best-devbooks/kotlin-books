Venkat Subramaniam writes with a strong opinion about what idiomatic code looks like, and this book is at its best when explaining Kotlin's DSL-building features — an area a lot of other introductory books skip entirely. Slightly dated on coroutines given its 2019 publication, so pair it with a newer book for async topics.
